# v1.102.0 — 导演台创作控制与独立采样扩展（EXP）

本版在已发布源码基础上保留原738个节点的顺序与接口，追加30个独立入口，总计768个。既有工作流、采样默认、用户模型与有序多LoRA选择不迁移；未知组合保持委托并警告，真实张量、文件与完成记录错误仍校验。

## 创作与交互

- 导演台增加区域／裁剪控制素材及首中尾关键帧编排；原生、标准双采与HyperFlow分别保留各自的条件和阶段合同。区域强度不是画面坐标的硬保证。
- 全片字幕侧车、事件／收尾模板与导出错误状态补齐；Windows临时文件替换、慢历史响应与恢复检查加强。
- HyperFlow两阶段进度、完成报告与实际条件绑定修正，不将配置成功当作实际消费成功。
- Control MODEL 的真实内容、区域几何和阶段身份绑定加强；不把可变观察器计数当成可移植缓存身份。

## 独立实验功能

| 功能 | 保留的实际范围 |
| --- | --- |
| 投影工作集与INT8行分块 | 按真实算子分块；保留LoRA顺序与原调用，不宣称所有后端提速 |
| 参考时序打包／逐步缓存 | 独立选择和实际调用审计；近似策略不冒充逐位等价 |
| PTD专家 | 独立安全转换、专家加载；完整4／6步与同画布2+2／3+3，不是通用加速LoRA或放大4+4 |
| FreeVideo H21 v4 | 新Light／Medium 8+3、High20近似缓存、Max20全算；旧FreeVideo家族与配置不替换 |
| MC接缝算子 | 默认关闭的独立Sigma／Refine／Join实验节点；独立算子接口不等于任意长视频一键组合认证 |

FreeVideo High修复FP32原地采样导致缓存历史别名被覆盖的问题：只为抽样历史建立独立副本，保留阈值、窗口、20步及原条件，不偷偷改成Max。自有隔离worker显式禁止写入pyc，避免`-I`忽略环境变量后污染密封源码身份。

## 已审工作流与验证

2026-10-23原审片84组通过；2026-10-24复审9条不同完整AV全部通过，覆盖原10组失败配置。94组的来源和成片SHA在本地分别保留；技术页点击不提升为算法或设备资格。公开示例见[按用途分类的已审来源目录](../examples/workflows/90-h21-reviewed/README.md)。个人素材、权重、审片反馈及研究交接文件不分发。

竖屏8秒放大双采保留本次通过的LOW448×800→原学习型3D→576×1024，标准4+4、HyperFlow8+4和4+4分别保存。通过的区域强度及安静音频提示词按对应来源保留，不用旧失败配方替代。资源路径改为用户选择入口后不继承同素材的画质保证。

发布候选去重后1,961项CPU测试通过、0失败；1项需显式指定私有H07素材的额外测试未启用，未计作通过。80张来源图完成160次实际Core API／序列化往返校验，6张普通文字副本另行通过解包后的Core校验。原738个节点的实际既有输入默认和输出接口均保持兼容，仅HyperFlow增加两个可选的HIGH正负条件输入。

采用官方Comfy CLI实际打包，逐文件核对归档成员与内容，并在独立解包目录重新注册768节点及全部schema；未初始化CUDA。测试中的第三方弃用与夹具线程退出警告保留，不包装成零警告。训练模型AV与人工音画验收来自上述固定样片，不为打包重复采样；此轮不重启用户服务或重跑整套浏览器交互。CPU检查、完整模型执行、人审及发行包检查分别记录。
