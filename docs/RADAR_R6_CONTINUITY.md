# RADAR r6 连续性与画外声音配方（指定UI已人审）

导演台“更多 → 镜头证据与规则”有两个填表按钮。只填**空的规则表单**，现有草稿不会被覆盖；默认作用域为本镜。不是自动保存、编译、采用、排队或新资产库。

1. **角色道具连续账本**：填写全片唯一时间线、稳定角色ID、本镜presence、道具持有人/状态、实际已采用末态、允许变化和结束状态。未知状态明确未知；文字声明不自动成为观察事实。依赖前镜事实时在已有创作意图中明确镜头UUID和已确认evidence SHA，不把partial x0、LOW partial4或未采用候选当成已采用电影末态。
2. **画内／画外对话**：填写有序参考包/SHA/role_id、本镜visual/voice开关、声音策略、实际master/完成回执和局部对白事件。A离场仍画外说话时，参考Route显式A visual=false/voice=true，B在画另有自己的视觉声明。规则文字本身不会自动修改Route、参考编号或音轨。

打开“参数声明／本次取值”，在parameters填本次值；未填写的字段是明确待填例子，不是已确认事实或推荐镜头。点击添加快照，再编译待审候选、核对原稿与实际接线，最后明确采用。事实、创作意图和规则仍分别留档，原稿保留；可回退和撤销，参数或明确跨镜事实改变会使已采用候选失效。正常保存与重开沿已有项目合同。

## 声音与全局时间线

已有配音时只用一份全片master作drive_audio；确认实际完成源音后，可用既有lock_source/final_audio保持原声。各人物的voice anchor是reference_only，不是另一条master，不静默替换或混入驱动音频。

没有源配音时保持原生联合生成，用既有1.92 Speech Scope与外置Prompt Relay写局部事件；不能把只说一次的台词写进全局重复条件。全片事件与sample时间线只有一个原点，各镜/窗不偷偷重置；配方不会解析、移动或重写原事件。不冻结未完成LOW partial4音频，不强制TTS/ASR替换，不承诺硬时间隔离或声纹锁定。

参考包Load/Route/Apply仍在普通或分离式画布中独立连接，不把EAV/Relay藏入参考包。导演台规则不冒充模型接口或另一套执行器。

## 验证边界

真实JS填表函数及已有快照/候选/项目保存路径的受影响六文件58项CPU测试通过：默认本镜、拒覆草稿、一次字面参数替换、待审不生效、明确采用、保存重开、回退、参数变化失效、旧UI控制和候选依赖保留。独立QA项目的真实页面已验证两条配方填表、拒覆现有草稿、添加两快照、编译、显式采用、回退和服务端保存；新标签页从服务端重新加载，顺序、参数、快照SHA与已回退状态保持，原提示词/事件/素材仍为空。该指定UI已获用户通过，不是生成画质、身份或听感资格。

QA只声明全片0–5秒，而镜头原设置4秒保持原样，证明填表文字不自动改事件或镜头时钟；不是可直接生成的5秒配方，使用时必须自行核对实际时长与事件。曾被浏览器确认弹窗阻挡的重开尝试没有计作通过；之后新标签页直接读取服务端项目成功，没有代点击隐藏确认。Core `/api/` 与旧不带前缀入口均使用同一静态模块，原保存/执行路径未改。
