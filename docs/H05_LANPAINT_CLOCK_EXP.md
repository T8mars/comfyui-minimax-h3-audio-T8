# H05 N03：独立 LanPaint 音频时钟适配（EXP）

新增 `MiniMaxH3LanPaintClockSamplerEXPT8`，只在明确接线时生效。旧 Prepare、
Composite、采样节点和工作流默认不变。已取得指定真实画布 5 秒运行和完整音画
证据。Prompt First 案例效果未达标；随后单改 Image First 的固定案例已形成
待人审候选，不是质量批准、通用补丁组合或断点恢复资格。

## 为什么单独增加入口

本机 Core 0.38.0 的 H3 模块有 `time_shift_sigma`，但没有 `time_shift_slope`。
已安装 LanPaint 的联合导入失败时，会把两者都置空，跳过其音频时钟分支。
新入口从已安装依赖加载一个独立模块命名空间，绑定实际 Core 映射和解析导数：

`to_shift * from_shift / (from_shift + sigma * (to_shift - from_shift)) ** 2`

不会写 Core 或 LanPaint 文件，不会改普通 LanPaint 模块的两个全局变量，也不
打包或复制外部采样器。LanPaint 算法仍来自独立安装的 GPL-3.0 依赖；公开发行时
需要保留准确的第三方依赖／许可说明，不把本地验证当成发行许可审查。

当前适配明确针对 LanPaint `2d7912f9a5efe5ece8de334c7ca18317b8288c39` 的四份
已审源码，以及本机固定 Core H3 API。源文件或实际时间函数不匹配时报出明确
错误，不自动下载、升级、降级、修改 Core，或静默换用其他采样算法。其他版本
仍可使用原 LanPaint 路线；新适配不拦截旧节点。

## 接线及边界

Source Clock／Conform → 同源逐帧 MASK → 原 LanPaint AV Prepare → 新时钟采样入口。
现有 NOISE、GUIDER、SAMPLER 和 SIGMAS 保持外置。采样配置写到原生克隆的
MODEL／GUIDER，保留所选 LoRA 顺序和 hook 委托，不清空未知补丁。

外部算法自身会在串行采样上下文临时替换 Core 的采样函数，完成／异常退出时
恢复。新入口不宣称并发线程安全，不能嵌套进入另一 LanPaint 采样上下文。

SIGMAS 必须明确位于 `[0,1)`：该已审版本的 VE 转换 `t/(1-t)` 在 1 有奇点。
选择源片重绘时，须用画布上的显式部分去噪调度；入口不偷偷夹值或裁掉第一步。
外层步数不等于总 NFE，LanPaint 的内层思考会额外调用去噪网络。

报告统计实际音频时间映射／导数调用；没有真实覆盖不会返回成功资格。输入／
输出必须是有限、同形的 H3 两音画流，逐流 MASK 明确。生成音频经过 VAE／导出
不承诺与源 PCM 精确相同；最终使用源音轨和可选回贴应单独记录。

## 本地验证

新增 6 项 CPU 检查使用真实 Core 和真实已安装 LanPaint：解析导数与 float64
autograd 一致、独立命名空间、tiny H3 音画实际执行、LoRA／hook 保留、异常传出
并恢复原函数、实际时间函数被替换或含危险常量时提前拒绝。没有初始化 CUDA。
追加注册前后完整 682 个旧 schema 精确一致，新入口位于第 683 位。

原 N03 Union2 的杯子首尾回色失败证据继续保留。新路线指定案例实际完成原生
另存、保存、关闭、侧栏重开和运行：512×288、120 帧、24fps、5 秒，耗时
Prompt First 耗时 265.604 秒，实际时钟映射和导数各调用 20 次。外层 20 步、内层配置 2，
总去噪网络调用数没有单独计量，不写成“20 NFE”。

两份最终原生 AV 检查点均经真实加载器核验；两输出端口的 tensor 并不相同。
原始片和可选回贴片均完整解码，源片、两检查点及输出均保留。回贴的音频替换
比例为零，但 AAC 导出后的解码 PCM 与源并非逐值相同，不能扩大为无损音轨承诺。

完整 120 帧目标 ROI 实看：开始几帧仍偏米色，其余可见杯子为浅蓝灰并带斑点／
图案，不满足全程纯蓝杯子的目标。因此只关闭该案例的运行机械门，不推荐此图，
MASK 人工批准及最终效果仍未完成；回贴不掩盖原始片失败。

已核对固定作者示例的实际 edge：解码接 sampler 的 output（端口 0），与本例
一致，不能把失败归因于接错 denoised_output。作者示例使用 BasicGuider 和
Image First；首例使用同一种 guider，但显式选了 Prompt First。

第二次实际画布另存、保存、关闭、侧栏重开和运行只改 `prompt_mode=Image First`
（另换输出前缀以保留首例），source／MASK／seed／模型／20 外层／2 内层／调度
全部一致。实际空缓存完成 260.179 秒，两音画检查点、完整 120 帧、PTS 和立体声
再次核验。完整目标 ROI 实看：首帧即蓝色，部分遮挡时只判断可见部分，完全遮挡
[74,99) 不假称有颜色证据；重现后保持蓝色至最后一帧，另一人的杯子仍为米色。
这支持该固定模式干预有效，不证明任何素材都适用，也不是衣服重绘的验收。

两次同槽 audio tensor 和对应导出 PCM 逐值相同，video tensor 确实改变。该对照
不等于导出 PCM 与最初源片相同；后者仍不是 exact。所有失败片、两次原始片／
回贴片均保留。当前候选的 MASK 边界、人物、动作、口型和听感仍待用户集中审核；
未进入推荐示例或发布。
