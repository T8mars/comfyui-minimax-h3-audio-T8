## 2D六档潜空间放大

denoised_output，输出继续接原有二采潜空间协调、高分辨率条件和采样器。
仅视觉流进入网络；原音频、音频mask和其它元数据保留，视频mask匹配目标尺寸。
不需要重复加载底模，不改变4+4的步数或sigma。

匹配权重放 models/latent_upscale_models，已核文件为
minimax_h3_latent_upscaler_2d_conv_v1_bf16.safetensors。文件约364MB，SHA256
f35307b93a19415acf1ec544148592f2a9c76c67421db5ee41fdfbe6360ecf44。
此SHA用于记录所测资产，不是禁止换模型的名单；真实缺键/尺寸错误仍报告。

导演台标准双采设置可以选择2D并设置锐度1–6；旧项目缺字段继续使用3D。
MP仍为十进制总像素，尺寸按32对齐。chunk_frames以潜空间帧计，0表示整段；
每块自动增加网络实际时间感受野，取消或失败后不返回部分结果。
1–6是训练条件档位，较高档位不保证更好的运动或纹理。
新2D入口不继承旧3D配方的4倍几何上限，允许用户指定其它正比例/合法尺寸；
仍按32对齐并检查所选长宽比容差。5倍与缩小已用tiny网络核实际形状，真实权重画质
目前仅有上述2倍测试。超出已测范围不等于已验证，不自动降级为插值。

固定LBH源码87d8822的模型组件按MIT许可抽取，完整通知见
[代码许可](../THIRD_PARTY_NOTICES/LBH-2D-LICENSE.txt)。权重卡独立声明Apache-2.0。

## 提示词定向编辑

H3 Prompt Edit Guidance 接同一媒体准备得到的原文与改后文条件，允许文本token
长度不同。first_step之前只用原文；强度0使用原文、1使用改文，其它值计算两分支。
每一分支保留原生位置布局，没有默认移动媒体position；效果需完整成片验证。
同数量但不同内容的参考图、时钟、guide或mask会明确报错。

H3 Prompt Edit Report 在采样后接同一guider与LATENT，记录真实分支与物理forward。
已有模型wrapper继续委托。接口不自动请求LLM、改写对白或增加重试。

当前固定4秒对照分别执行8/8/14次DiT，实图已保存并完成独立画布保存重开及全片播放。
普通改写、定向编辑和原文对照三条原片均已获指定片的画面/声音人审通过。
该样本普通改写比1.15强度、延迟2步的定向编辑更好完成合书动作；不据此承诺定向编辑
优于普通提示词，也未接入导演台默认路径。其它强度/内容仍需各自比较。

## LoRA采样区间

H3 LoRA Window 生成原生HOOKS；通过Core的Conditioning Set Properties接入条件。
previous_hooks可串多份LoRA，各条保留强度和区间；不要再把同一份LoRA静态重复叠加。
H3 Multi LoRA Windows可直接用有序JSON列表生成带hook的条件，包含name、strength、
start_percent、end_percent、enabled及现有可选解析策略。

区间使用所选模型原生percent_to_sigma，不是成片秒数；右端小于1时为排他边界。
一采与二采分别从各自MODEL和条件创建。原有静态加载器仍保持全程生效。
加载报告区分映射与执行；目前已用真实tiny Core采样核对全程与静态LoRA等价、
区间启停、多LoRA顺序和底模恢复。导演台单采、标准双采及现有五种HyperFlow路线
均按顺序接入区间条件；保存重开及内容身份已接入。区间使用模型完整扩散进度，
不是每阶段的局部步数占比。下述选定INT8路径以外的训练资产和可移植复用仍需各自验证。
选定INT8模型已完成8次真实采样，区间权重delta按配置切换；修复量化库存、写入、
尺度恢复与pin存储生命周期后，成片RGB/PCM与修前成功样例逐位相同，清理不再出现
旧pin警告。此机该4秒样例耗时约20分钟、主内存峰约112GB，不能当成无成本开关。
自动Stage复用在条件hook没有可移植身份时照常执行，并明确不产生跨次命中；
直接Stage及第二次调用已测，不借普通静态LoRA的缓存身份冒充区间组合资格。
本批指定区间LoRA原片已获画面/声音人审通过。三份命名Realism V2原资产仍需
原站授权，不能借这条通用窗口样片替代其实际加载与效果资格。

## 双采音频连续续采实验

H3 Two-Pass Audio（MiniMaxH3TwoPassAudioContinueEXPT8）是新增的显式接线选择。
coarse_output必须接一采SamplerCustomAdvanced的output口0；high_latent接已有
放大/协调后的HIGH输入，visual_noise接原二采NOISE，low_sigmas和high_sigmas接
实际两段步表。输出LATENT与NOISE一起接二采；其它MODEL、条件、采样器不改。

视觉latent与视觉NOISE继续由原路径提供；未完成音频采用一采output的连续状态，
二采初始NOISE的音频分量置零，不额外冻结生成区音频或增加采样。采样器内部的随机
过程仍由所选采样器控制，节点不修改LCM/SDE等内部重加噪。Core按原生latent输入/输出约定
负责缩放；节点不手写音视频shift转换。高采模板锁定的已知音频区域及mask保留。
LOW末sigma须等于HIGH首sigma，并由用户使用一致的音频时钟；该结构校验不代表
任意模型/采样器组合都等价。旧工程和导演台默认路径不自动改线。

实际tiny Core回归覆盖原生分段续采、未知NOISE委托、真实形状/NaN/步表错误；

不能证明训练模型声音改善。FL/Ref的3+3新片各完成6次DiT，保持原配置，仅改变
初始音频续采接法。翻书原author-parity配方的LOW/HIGH时间点不同，不能直接接此节点；

单变量修复。这三条新片随后复审均为画面通过、声音失败，不能称为声音修复成功。

## 最终音轨ASR复核

H3 Final Audio Audit接最终保留的AUDIO，返回同一对象，既不改PCM也不自动重试生成。
选择本地已安装的ASR模型目录；默认仅整轨识别一次，windows_json可给最终时间轴上的
start/end/text。显式选择explicit_final_windows时，每个窗口单独识别并报告调用次数；
重叠窗口不会被合并成可信的整轨字错率。

实际已见整轨ASR漏识重复句、阳/陽字形产生分数差异；这些是识别估计，不能当模型没说话
或声音不合格的自动判据。逐窗识别可以定位，但仍须听原音轨。退出、取消或失败按选择
释放ASR进程；不下载替代模型，不调整增益、限幅、采样率或时间位置。
