# 局部颜色稳定（显式后处理，EXP）

`H3 Masked Color Stabilize / 局部颜色稳定（显式后处理 EXP/T8）` 用于生成结果中
选定衣物／物体忽明忽暗、跳色的情况。它明确修改解码后的 RGB；不代表原始模型已
消除闪烁，也不改采样器、latent、声音、帧数或几何。未连接此节点的旧图不变。

连接方式：完成采样 → AV Decode → 本节点 → 原有局修 Composite → Trim／Save。
保留 Decode 直接接出的原始结果，便于对照。`strength=0` 返回原输入对象；也可断开
节点旁路。模型及 LoRA 的选择、顺序、强度不参与本节点的准入判断。

输入为生成帧、相同帧数与尺寸的原片、逐帧选区，以及一张与原片指定帧配对的目标
参考。`source_reference_frame` 选择配对的原片帧；`target_reference_index` 选择目标
图片批次中的对应图片。参考可以是明确标注的人工设色输入，不得当成生成成片。
选区由调用方提供，本节点不自动识别人物、衣服或镜头。

`detail_source=generated` 是原有默认：在选区内统计 Lab 均值，用目标参考与配对原片
的差建立颜色偏移。之后每帧跟随原片的实际光照／白平衡，调整生成帧的选区颜色。
保留生成帧内 Lab 细节残差；均值稳定不代表局部明暗、纹理稳定。这一路径的开衫
候选经用户复审仍有闪变，不能作为已解决此问题的示例。

`detail_source=source_recolour` 是显式的纯换色选项：使用同一原片当前帧的衣料细节、
褶皱和遮挡，在选区内应用目标参考相对配对原片的 Lab 颜色偏移，不再保留生成的
衣料纹理。适合“只把这件衣服改成蓝色”；不适合换款式、材质或生成新的形状。
可以复用已有模型成片接入本节点，无需为了这一步重新扩散采样；也不能把这一
换色结果当成 H3 原生编辑时序质量通过。原始生成结果须保留独立对照。
此模式启用时，选区内的软边混合也以原片为基础，避免把旧生成片的闪变混回边缘；
`strength` 控制原片上的换色量，精确为 0 时仍旁路整个节点并返回原生成输入。

也可把 `repaired_frames` 与 `source_frames` 都接原片，以本节点的输出作为明确设色的
视频控制输入，再交给现有 VAE／局修采样器作低噪声细化。此时节点位于采样之前；
输入换色、模型原始解码和最终合成应分别保存。是否再次采样由用户决定，单纯换色
没有重新加载大模型的必要。该用法不证明模型能从灰衣直接稳定地改成任意服装。

两种模式超出 sRGB
色域时固定亮度并降低色度，仍可能影响饱和度，极端亮度会受可表示范围限制。没有
跨帧混合、光流变形或补帧。最终效果须看完整运动，不能只用均值指标判作通过。

- 零选区像素及生成帧额外 alpha 通道逐位保留；输入张量不原地修改。
- 后续 Composite 仍使用原始精确选区，把零 alpha 区域还原为原片，保留完整原声。
- 空选区／空参考选区报告旁路，不假称已经稳定。可改选参考帧中可见的目标。
- 接口要求有限、归一化的 sRGB IMAGE；HDR 需先显式转换，错帧数、尺寸和引用索引
  报告实际输入合同错误。没有模型白名单、时长或 Stage 文件大小门槛。
- 有意闪光／变色需要自行关闭或分段。选区追踪错误、遮挡错误、生成的形变及手部
  伪影不由颜色校正修复。

新增节点追加在原有 787 个注册节点之后。CPU 合同测试覆盖已知跳色、光照变化、
细节残差、软选区、alpha、输入不变、旁路、真实输入错误及色域；实际视频资格和
人工评分另外记录，不扩大为任意服装或模型的质量保证。
