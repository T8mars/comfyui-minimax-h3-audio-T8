# 局部返工与色漂的增量验证

本次复用已有 LanPaint AV 桥、Core 遮罩合成、局部返工窗口及色漂审计。
不另造局修系统，不改变旧采样、sigma、3D upscaler、音频默认或模型选择。

实际复现并修复两个问题：

- 显式 `bounded_candidate_exp` 在接缝合法时，会把该接缝的颜色修正继续带过
  后续硬切。现在到下一个声明边界，或检测到后续硬切/大闪光时停止；报告记
  实际停止帧和原因。默认 `report_only` 仍原对象返回，不自动改有意的光色变化。
- LanPaint 的非有限 MASK 或候选可通过 `0 * NaN` 污染非编辑区。现在在潜空间
  mask 传输、源 IMAGE、合成候选/遮罩及合成音频入口验证有限值；正常输入的
  mask 压缩、混合和声音算法未改。错误是实际数值错误，不是类名/模型白名单。
- 候选音频较短时，合成曾连未编辑的原声尾部一起截短。现在保留来源 PCM 长度，
  只有实际选择了候选未覆盖的区间或淡化范围才报告缺失样本；视频局修不再因此丢声。

验证分开记录：

1. 真正的 Core Euler 采样消费者和 tiny random Core VAE，以黑、白、0.25、
   细线、遮挡五种 MASK 运行；检查采样 latent 已保护区、音频 latent 和输入不变。
2. 单列原始 VAE 解码候选在像素 MASK 外的变化，不能用最终贴回反推生成器保护。
3. 再用实际合成消费者核最终 MASK 外逐位相同、原 PCM 逐位相同；既有窗口
   消费者覆盖双主体交叉遮挡、两镜硬切、非法跨镜范围和拒绝越界的原始候选。

一个 tiny random 遮挡样例的 latent 保护误差约 `1.49e-7`，原始解码候选
MASK 外最大误差约 `0.00520`，最终合成 MASK 外及源 PCM 位相同。这些数字只
说明该 CPU 回归链的区别，不是生成质量或训练后模型能力。

既有双采接缝五组门禁与窗口回归通过。后续已补真实训练模型的两人局修、逐帧衣物
选区和人物交叉遮挡；分别核对采样 latent、原始解码候选、编码前合成张量的遮罩外
RGB 及完整源 PCM，不将其位相同结论扩大到有损 H.264/AAC 解码文件。早期样片存在
渐变换色/衣摆瑕疵，机械保护通过没有被写成效果通过；新配方
和整片的人物 ID/肤色/遮挡观感单独验收，见 [完整验收补充](NOV08_FULL_ACCEPTANCE.md)。
H3MD 跨段趋势不是这里的局部色漂算法；不能将本修复称为 H3MD 的实现或性能/质量
验证。有意换光、HDR、纹理损伤仍由原有 report_only、拒绝和显式候选流程处理。
