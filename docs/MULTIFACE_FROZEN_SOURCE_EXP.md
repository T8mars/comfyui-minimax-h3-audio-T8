# 多人 Face 分离采样：显式来源保存／加载（EXP）

新增 `Multi-Face · Save Exact Source Inputs` 与 `Load Exact Source Inputs`，各角色仍独立连接原 Stage Sampler、Stage Save／Load、来源审计、解码、Stitch 与 Composite。原双人／三人节点、八十四份 Face 工作流、采样公式和审图控件不变。EAV／Prompt Relay 保持外置。

新工作流位于 `examples/workflows/56-face-refine-split/frozen-multiface-source-exp/`：双人、三人各一份 `full_save` 与 `cold_delivery`，共四份，显式使用已有隔离 H264 导出节点。

## 如何使用

1. 完整图设置当前源片、参考图、模型和 SAM 检测文本。SAM 的人物索引仅属当前镜头，不等同角色身份；需要核对角色对应。检测文本可明确设为 `person`，不要把 H3 生成提示词填进这个检测文本。
2. 每个角色有两个独立保存：原 `Stage Save` 保存已完成候选；新 `Source Save` 保存**当次** Face plan、来源窗口和编码 AV。新节点默认 `confirm_save=false`，需明确开启。它校验实际可移植完成 Stage，并绑定完整父片 RGB 和原音频，不储存模型／可执行对象、不自动接受修复。
3. 冷图每个角色分别粘贴其 Stage 和 Source 的路径与 SHA。四个值不能混角色或混任务；继续读取同一完整源片和音轨。新 `Source Load` 严格验证它们以及原 Stage 的来源审计，再将原计划／窗口／AV 交给已有独立节点。
4. 冷图不重新运行 SAM、VAE **编码**、条件编码或 H3 采样；候选的视频 VAE **解码**与原 Stitch／Composite 仍运行。冻结 job 的 EAV／Relay 已包含在 Stage，不会再应用一遍。需要更换计划、音轨、参考或采样效果时运行新的完整图，不修改旧快照。

这是显式数据快照，不是自动缓存。它解决原冷图重新推断 SAM 计划的哈希变化问题；原 SAM plan 还包含当次显存释放观测。既不删这些字段，也不放宽原计划／来源／AV 哈希检查。
