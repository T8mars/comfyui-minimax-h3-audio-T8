## 新能力怎么使用

可编辑图集中在 [96-nov05-exp](../examples/workflows/96-nov05-exp/README.md)。

| 需求 | 入口 | 默认及边界 |
| --- | --- | --- |
| 已完成采样重用，解码失败后恢复 | [Stage Sample or Reuse](NOV05_STAGE_REUSE.md) | 默认 disabled；导演台可选接入，Creator 可连接 Workspace 并核验完成凭据 |
| 双采高低分关联噪声 | [Progressive Paired Noise](NOV05_PAIRED_NOISE.md) | 默认 independent；Haar 为可选，仍接学习型 3D 放大器 |
| 新 TaoMate-HD 完整三步配方 | [TaoMate-HD LOW2 + HIGH1](NOV05_TAOMATE_HD.md) | CFG 1 时实际 3 次网络调用；不使用学习型放大器；两阶段可分接 LoRA 链 |
| CFG 1 负面提示词 | [NAG + Actual Calls](NOV05_NAG.md) | 默认关闭；空负面文字不等于关闭，统计实际参与情况 |
| 二采保护最终首尾 | [Delivered End Conditions](NOV05_REFINE_ENDPOINTS.md) | 默认关闭；在采样前加 latent 条件，不能保证 RGB 逐像素锁定 |
| 局部声音候选试听和选择 | [Local SFX Candidates](NOV05_LOCAL_SFX.md) | 默认原声；支持 H3／外部 AUDIO 候选，不冒充人声分离器 |

仍使用现有底模、LoRA、条件、解码和保存节点。不按模型名称、LoRA 数量或未验证组合
拦截用户；实际接口缺失、张量不匹配、数值损坏和缓存完整性错误照常给出具体原因。
未知组合不能取得伪造的缓存命中，也不会被静默换成另一模型或另一种采样。

## 现有能力的修复与补齐

- [音轨和交付](NOV05_AV_DELIVERY.md)：可选绝对样本端点与共同源时间原点，修正连续
  窗口的取整边界；浮点解码有限值检查；最终文件帧数、尺寸、时基、AAC 填充分别核对。
- [缓存](NOV05_STAGE_REUSE.md)：Stage 真实完成记录与内容身份；Qwen 前缀缓存绑定
  实际编码器、tokenizer、设备、dtype 和参数版本，避免旧 KV 错用。
- [局修与色漂](NOV05_REWORK_VALIDATION.md)：拒绝 NaN 污染保护区；显式颜色修正
  到后续硬切停止，report_only 默认不改画面。
- [配方兼容](NOV05_RECIPE_COMPATIBILITY.md)：修正新 Core 原生 PDD hook 的身份
  误报。0.41.1 原生 baked PDD 缺少构造接口的真实限制仍在，T8 动态适配路径另行验证。
- [导演交互](NOV05_CREATION_CONTRACTS.md)：素材重排、旧回调、切镜切项目、逐字对白、
  保存回读和双标签检查已补齐；本轮未复现需要重写导演产品代码的新故障。
- [原生参考片段](NOV05_NATIVE_REFERENCE_SLICES.md)：用已有节点准备视频和配对音轨
  窗口，明确局部时间原点与引用序号；不另造切片或长视频队列。

## 自动检查和实际验证分开

自动检查覆盖真实小型 Core 消费者、实际 codec、阶段保存恢复、多个非零 LoRA 的
身份变化、新旧 Core 接口，以及独立浏览器中的工作流导入和回读。兼容检查涉及本机
Core 0.44.0 和固定 0.43.0、0.41.1 副本；不是所有节点在三版上的全量认证。

训练模型 GPU 验证单列 TaoMate-HD、独立/Haar 双采、NAG 关闭/空负面/有负面、二采
端点条件，以及 H3/MMAudio 声音候选。每项保留真实执行、网络调用、原成片和完整解码
记录，最终片才交人工审查。指定自然双人遮挡、静帧、参考窗口、两场景长链、解码与性能基线已另完成实测和审片；
任意第三方补丁、任意编译器、所有素材语义保持或公平性能提升仍无通用保证。

已有通过的 4+4 长视频续接算法、学习型放大器、音频和默认参数没有被新实验替换。
新选项与原方案并存，未人工通过的新片不标记为推荐或已验收。
