# TARA 参考动作时间对齐（独立研究，未集成）

完整方案复审已结束：普通关闭及仅时间偏置版本的画面、声音通过；完整“坐标对齐＋时间偏置”版本的声音通过，画面仍有半脸问题。动作对比为“差别不明显”。因此完整TARA未通过验收，按原方案“无可见收益则不集成”处理，已移除未发布候选的标准节点注册入口。源实现、完整执行图及失败媒体保留用于独立研究；仅偏置版本的质量通过不等于完整方法通过，也没有证明动作改善。

此前开启对齐的4秒原型和2秒节点样例同样被指出脸部缺失/变形，原失败记录保持。不能把可解码、调用次数或帧变化相关性当成质量通过。标准扩展不包含可选取的TARA节点，原研究工作流应使用对应冻结研究候选复现，不能宣称能在当前标准节点列表直接运行。

独立研究节点 `H3 TARA · 参考动作时间对齐` 用于带动作参考视频的 H3 条件，研究实现仍保留默认关闭。普通提示词、旧工作流及原模型保留；执行时间坐标/偏置计算本身不加载 TARA 训练权重，也不是加速 LoRA。能执行这些计算不等于普通底模已具备作者训练后的动作迁移质量，作者的训练展示不能记作本原型的现有实测效果。

连接顺序：本次实际条件对应的 MODEL 和 positive → TARA → 原有采样设置和采样器。多阶段使用每阶段对应的 MODEL/positive。`motion_video_ordinal=0` 表示参考列表里的第一个视频，不计静态图片；1 表示第二个视频。

开启时，节点明确选用 `pytorch_explicit` 分块注意力，调整所选动作视频的时间 RoPE，并只对目标视频 query → 该参考视频 key 加有界时差偏置。每个 query 块仍使用全部 key，不把不同 key 分区的 softmax 简单平均。时间单位为秒，默认 window=0.2、falloff=0.25、strength=2、cap=4。可能增加计算成本，不作为提速开关。

关闭时直接返回原 MODEL 对象。`bias_strength=0` 只关闭偏置，若 `align_clock` 仍开，RoPE 对齐仍生效；完全关闭应取消 `enabled`。上游 block/attention owner 保留委托；若上游自行旁路，不能把安装报告当成实际生效证明。报告只描述安装请求，不是采样完成回执。

`align_clock=false` 仅保留原生 RoPE，不关闭时间偏置。两路视频的偏置时钟各自从动作起点对齐，不将文本和其它参考占用的原生坐标跨度算作动作时差。此前这个独立开关会误用原生绝对起点，导致偏置整体压低参考或偏向它的尾部，现已修正；完整坐标对齐仍可自行开启，不强制换模型或更改旧输入。

偏置组件对照选择 `align_clock=false`，不替代完整方法。完整方法另以 `align_clock=true`、相同参考、种子、模型、步数及画幅执行，完整记录200次坐标对齐和200次偏置调用；其成片与前次同配方完整方法逐字节相同。组件对照为0次坐标改写、200次偏置调用。两者都不等同于作者专门训练后的效果资格，也没有静默改写用户旧工作流。

复审分别保留普通关闭、完整方法及仅偏置三个生成版本；每版独立记录画面和声音，动作偏好另记。完整方法未证明可见净收益且损伤人脸，不晋升为正式功能或推荐配方；旧候选节点注册和安装报告不等于产品质量准入。原四段首尾帧/锁原声接受结果保持。

复测时先更正了样例配置：旧失败样例使用通用 EMA B 四步 LoRA 和 `dual_clock_euler/native_flow`；本项目既有参考视频验证配方使用 `minimax_h3_ref2v_turbo_4step_v0.1_comfyui_bf16.safetensors`、强度1、四步 `euler/simple`、video/audio shift 12/3。这里是显式选择的样例配方，不是节点自动换模规则，也没有禁止用户其它模型和采样设置。不能把不同加速配方的差异归因于单一TARA参数，更不能保证换LoRA即可修好所有脸部问题。

更正配方的两秒开关完整片均已执行；二者只有 `enabled` 不同。开启版4次模型计算、200次对齐/偏置注意力，完整48帧可解码。四秒复测另外按实际原生107帧网格取参考源的107帧，RGB逐帧一致，无拉伸/插帧，交付仍为96帧。新四秒完整方法复审仍失败；旧人审失败记录不改成通过。

输入参考、关键帧、文本和音频的直接坐标仅按上述选定视频范围改变。联合模型的最终画面和生成声音可能受到连带影响；锁原声仍使用既有明确的源音轨交付链路。

独立原型曾完成指定完整 Ref2VA INT8、EMA B、4步、480×832、96帧开关对照：各执行4次模型计算及200次 block/attention。机器观察到帧变化更相关，但用户否定了画面质量与可见动作收益；这份原型仅保留为失败证据。

公共节点也曾完成独立整图 GPU 执行：同一组完整训练模型，取参考源前56帧，生成2秒、480×832、48交付帧，执行4次模型计算及200次对齐/偏置注意力调用。该片同样人审失败；完整解码不抵消人物质量问题。两份失败原件及原接线分别保留，不把任意模型/补丁组合、公平性能比较或人工质量验收一并认证。默认保持关闭。
