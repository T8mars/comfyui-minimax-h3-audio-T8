# H24 周期音画循环（实验）

这是生成过程中的周期补边、时间旋转和解码裁剪，输出一段可供重复播放的音画。它与已有逐段长视频循环、播放器循环分别使用，默认关闭。现有 MODEL、LoRA 顺序及强度、采样器、步数、sigma 和保存节点继续由用户选择。

候选提供三个节点：

| 节点 | 输入与输出 | 用途 |
| --- | --- | --- |
| `MiniMaxH3PeriodicAVSetupEXPT8` | MODEL、原 AV LATENT、开关 → MODEL、循环计划、报告 | 从真实视频与音频张量确定时钟，开启后安装周期预测。 |
| `MiniMaxH3PeriodicAVDecodeEXPT8` | 采样结果 LATENT、循环计划、视频 VAE、音频 VAE → IMAGE、AUDIO、报告 | 开启计划按周期解码并裁剪；关闭计划委托既有完整原生解码。 |
| `MiniMaxH3PeriodicAVAuditEXPT8` | 设置输出的 MODEL、`after_sampling` → 报告 | 连接采样结果建立执行顺序，读取实际调用记录。 |

接线顺序：原 MODEL 和原 AV LATENT 接设置；设置的 MODEL 接原有采样器或 Guider，原 AV LATENT 仍接采样输入。采样结果与设置输出的循环计划一起接循环解码，两 VAE 保持用户选定对象；IMAGE/AUDIO 接现有保存节点。审计可以单独接出，`after_sampling` 连接该采样结果。

`enabled=False` 会立即返回原 MODEL，不查看未启用的循环参数或 latent。关闭计划不包含伪造的循环几何，解码完整委托既有路径。开启后的计划是进程内专用类型；它表示裁剪几何，不是采样结果的内容回执，不能证明任意同尺寸 LATENT 来自对应 MODEL。审计也不会把一条顺序连线当作结果身份认证。

## 时钟与计算量

开启时要求实际视频 `[B,24,5k+2,H,W]`、音频 `[B,32,2,round((17k+5)×40/24)]` 匹配，且 `k≥1`。设置从视频 T 反推 `17k+5` 帧，再核对音频的真实长度与有限值。实际尺寸、接口或数值错误仍会报出。

输出视频从 `17k+5` 帧裁为 `17k` 帧，音频按 `17k/24` 秒裁剪。每次模型预测可使用一或两个视图；视频始终只取第一视图，第二视图只参与音频融合。奇数 k 时第二视图的 `floor(k/2)` 旋转不是精确半圈。模型预测次数、内部视图次数和采样器步数需要分别读取。

默认每侧补一组 17 帧。17 帧对应 `28⅓` 个 40 Hz 音频 tick，实际使用 28 tick，因此存在 `−⅓ tick`（约 `−8.333 ms`）的补边量化差，报告明确列出。`pad_clips=3` 的每侧 51 帧对应 85 tick，可消除这一项取整差，但会增加每次预测及解码的长度。没有随意设置补边资源上限。

只有部分 k 能使周期音频 tick 和视频周期完全相等。报告提供周期、补边、旋转各自的有理数误差；把 PCM 裁到视频时长不等于证明波形相位连续。节点不执行后处理交叉淡化、重采样、补帧或反向播放修补。

## 用户补丁与控制边界

模型和 VAE 不按类名、来源或 LoRA 组合准入。未知外部包装继续保留并提示风险。边界补噪绑定实际采样变换及有限的 `noise_scale`；零幅度、DisableNoise 和遮罩会保留其实际含义。无法绑定的采样变换仍委托执行，但报告明确标出边界新噪声未应用，不冒成功启用。

自动控制绑定只认实际完整配对：owner 的原生可变状态接口、已注册的 bound diffusion wrapper，以及每个声明注入层对应的 block-patch 链。绑定后使用分支独立的控制状态，重绑该分支回调；准备、前向、块回调、迁移和清理通过同一组身份排序的锁进入。原权重、VAE 和无关用户 hook 保留。该保护不认证共享权重加载、VAE 或任意用户闭包的一般并发安全。

未能确定完整配对的包装保留执行，并在报告中列为未绑定。Regional 派生缓存的保存、清空、恢复和原有校验已接通；**非空 RegionalGate 的周期时间映射及其闭包 runtime 隔离尚未实现**。不能把派生缓存用例当作全区域控制通过，也不会删除其真实时钟、shape 或完整性校验来掩盖不匹配。

## 指定 GPU 样例证据

本地 `gpu-loop-v1` 是固定镜头蜡烛、自然底噪的 T2VA 样例：完整 FL2VA INT8、EMA B Turbo 强度 1、832×480、输入 107 帧、seed 26102631、`dual_clock_euler` 完整 4 步、视频/音频 shift 12/3。默认一组补边、两个视图。代码与资产身份在本地回执中保存；来源和许可证见 [H24 来源说明](../THIRD_PARTY_NOTICES/H24-SOURCES.md)。

| 实际观察 | 结果 |
| --- | --- |
| 采样器完整步数 / 内部模型前向 | 4 / 8 |
| 单圈视频 / 原始双声道 PCM | 102 帧 / 136000 样本，32 kHz，4.25 秒 |
| 重复三圈 | 306 帧 / 408000 样本，12.75 秒，无累计样本调整 |
| 后处理交叉淡化 / 重采样 | 均无 |
| 单圈 MP4 SHA256 | `8efaf0a06de3db956266f0ff87ea62414bd3bd39637f8712ab4a0eb95c3cc196` |

该例的帧首尾 RGB 平均绝对差约 0.00472，普通对照约 0.00885；两声道 PCM 首尾跳变约 `1.3×10⁻⁶`、`1.6×10⁻⁵`，低于该波形相邻样本跳变的 p99。普通对照输出 107 帧、循环输出 102 帧，未暗裁为等长比较；H.264/AAC 成片与原始 PCM 的指标也分别保留。

这些只证明指定完整训练资产已执行、时钟和文件交付完成，以及少量代理指标改善。五帧抽样构图稳定不等于完整动作审查；2026-10-27，指定普通对照及三圈候选已获真人完整看听接受，画面、声音通过，循环接点评为自然，不保证其他提示词、模型或时长无反向、停顿、爆音，不宣称通用 GPU 质量或性能收益。运行时不会把该例硬编码成所有后续请求的认证。
