# 导演台交付与逐帧遮罩

旧工作流、774个已发布节点及既有默认值保留；追加逐帧MASK加载节点，标准扩展当前共775个节点。TARA独立原型未通过成片收益验收，已从未发布候选的标准注册入口移除。本次随已审完整配方同步GitHub源码；本方向追加1个MASK节点，加上完整配方3个节点，全扩展合计778。

## 关键帧与交付

导演台按最终交付的首、中、尾位置构建原生条件。小数秒输出使用明确帧数；原声短片的AudioWindow上下文偏移由同一纯时间计划计算。生成画布上的隐藏中间帧仍保留，图片编号和提示词引用按真实编码顺序一致。

普通节点的自然首尾默认值、原声、步数、sigma与learned3D放大器不随此修正改变。导演台普通提示词仍不要求Prompt Relay。单采、4+4与HyperFlow各阶段保留完整视频时轴及MODEL/positive配对。

## 制作并使用逐帧MASK

1. 在导演台准备“整片串播”，选中要处理的镜头，点“绘制当前镜头遮罩”。
2. 选择实际源帧，用画笔或擦除；拖动时即时显示。可撤销、清空本帧，或明确复制到一个帧段。复制后逐帧检查，遮挡帧应清空。未绘制帧为空；没有自动跟踪或插值。
3. 保存遮罩稿，再“保存并导出逐帧MASK”。可以下载ZIP；同一台Core的input/t8_masks也会保存可供节点使用的包。旧导出版本保持独立。
4. 添加“H3 · 已绘制逐帧MASK”，刷新文件选项，连接对应**完整原片**的RGB IMAGE序列，选择刚导出的包。节点校验完整源RGB24、画布、帧数及PNG内容，再输出MASK和帧映射。
5. 如需裁切、改帧率或缩放，让画面与MASK共用Source Conform的Frame Map。后续复用[局部返工](LOCAL_REWORK.md)的窗口、候选合成和显式采用；最终仍接原片AUDIO。

源RGB24校验针对编码视频的8位解码像素，不替代局部返工的完整浮点源身份及采用边界检查。原片、原声和项目稿均不由画笔操作改写；preview/reject仍按既有返工合同保留原片。MASK包不包含音轨。

## 从成片音轨识别字幕

在“整片串播”展开“字幕 SRT / VTT”，选择镜头，再展开“从已采用音轨识别字幕”。选择本地已安装的识别模型和语言，点“识别所选镜头音轨”。识别使用 CPU；结果先成为可编辑稿，确认文字和时间后再保存生成 SRT / VTT。手写与导入计划稿仍可独立使用。

识别期间可以取消；“读取上次识别”用于重新核对已有任务。切换项目、采用版本或音轨后，旧结果不会套到新片。词时间来自完整源片起点，采用范围只在组片导出时应用一次。原片与声音保持原样。识别不会认证说话人、口型或剧情事实，跨句裁切与重叠仍需人工复核。

实际音轨验证包含既有H3中文对白成片、独立生成的双人英语音轨、跨句裁切、静音，以及明确标记的人工叠加重叠输入。中文样例识别为“你在干嘛呢，我在这里啊，看看效果如何”，相对指定原文的字符误差为1/16；“呀/啊”没有被系统暗改。静音未生成字幕。对实际本地多语种模型执行取消或强制结束本任务子进程后，旧任务分别记录取消/错误，随后短任务可正常运行；源媒体、原始识别和手动修订各自保留。重叠输入仍出现重复识别，不宣称自然重叠对话或说话人识别已合格。

## 验证范围

可见首尾时钟覆盖原生、Relay、单采、4+4及HyperFlow编译合同；普通独立节点保留原自然首尾默认值。新增遮罩节点追加到既有774个节点后，原注册顺序保留。自动测试、真实媒体操作、完整模型成片与人工观感分别记录。

参考接线的限定回归包含两段都带音轨的视频：普通声音、声线参考、锁原声三种用途，以及视频次序交换。实际原生媒体加载器、音轨编号、提示词别名和编码器输入分别核对；声线参考仍生成声音，只有明确锁原声才使用锁定音轨。测试未扩大为任意训练模型组合或说话人质量认证。

独立[TARA动作时间对齐原型](H27_TARA_EXP.md)仅保留研究实现及原始实验接线，不注册到标准扩展，不作为上述导演台功能依赖或默认注意力后端。既有774个已发布节点、工作流、模型选择和加速配置均保留；没有根据本轮有限样例添加新的模型准入限制。
