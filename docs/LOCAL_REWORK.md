# 局部返工：人物、道具与细边缘

已有窗口规划、窗口提取、选择回贴节点也能处理非人脸区域。节点编号和接线不变；现在显示为 **Face / Object · 局部返工**，旧工作流仍可打开。

先把原片和每帧遮罩一起对齐，再选需要重做的帧段。可以只采用候选中的一部分；预览和拒绝都保留原片。

## 接线顺序

1. 需要变帧率、裁时或调整画布时，先使用 Source Conform。原视频的 MASK 通过同一个 Frame Map 映射，避免图片和遮罩分别缩放、取帧。
2. 用局部返工窗口规划选择帧段，再由窗口提取取得合法长度的画面和映射。模型所需的上下文不等于最终要采用的帧段。
3. 用自己的生成或编辑流程重做窗口。遮罩可以覆盖道具、衣物、局部背景或人物；不要求先做人脸检测。
4. 使用 Core 的 **Image Composite Masked**：原窗口接 destination，重做窗口接 source，逐帧遮罩接 mask，x/y 为 0，关闭 resize_source。两路应有相同帧数与尺寸。该步骤先保留遮罩外原像素。
5. 回贴节点接完整原片、已合成的候选窗口、对应 changed_mask 和原窗口映射。默认 `preview_only`；确认后选 `accept_selected`，可指定较小的采用帧段。需要保存多个窗口的决定时，使用已有 Window Studio 的提交与合成节点。
6. 最终视频配完整原片 AUDIO。候选窗口的声音不自动替换原音轨。

遮挡期间 MASK 应为空；空帧不会自动追踪、补框或延续上一帧的区域。对象再出现时，重新提供那一帧的 MASK。需要柔边时可以使用原有 grow/feather，但它们不负责判断边缘是否美观。

## 原片与再次返工

新规划记录完整逐帧内容身份，连缩略图看不出的细小变化也会检测。规划后换了原片，需要重新规划；在已采用的结果上再次返工，也应以该结果创建新规划。

旧保存计划保留兼容，并标明 `legacy_proxy_only`，表示它只具备旧缩略图级来源校验。它不会被冒充为新的完整内容校验。

范围外像素保持检查针对回贴前的 RGB；有损视频编码仍可能改变像素。来源、帧数、遮罩和采用边界的自动检查不能替代对生成质量的观察，也不能仅凭同尺寸候选证明其动作与原片对应。
