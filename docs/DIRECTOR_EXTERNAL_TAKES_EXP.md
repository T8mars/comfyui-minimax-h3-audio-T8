# 外部成片版本登记（本地 EXP，未发布）

将已上传的视频登记为当前镜头的一个外部成片版本；不是把视频参考自动当成生成结果。旧生成工作流、配置快照、采用与裁切逻辑不变，没有新增采样节点。

## 使用

1. 在导演台上传视频并选中素材卡片，先保存项目。
2. 点击“登记为本镜外片版本”，填写名称、选择来源类别，再明确确认。
3. 切到“输出”，在版本列表查看“外部成片 · 不可重采样”。登记不会自动采用；需要点击“采用此版”。
4. 可编辑采用范围、取整数帧、整片串播和导出工程包。裁切不修改原文件。保存项目后，采用版本与范围可恢复。

来源类别是人工标签，不证明模型、seed、采样配方或质量。外片没有生成配置快照，不提供“复制此版设置”，也不伪造 StageResult、MODEL 祖先或精确重采样资格。

## 素材与时钟边界

- 支持 MP4/MOV/MKV/WebM，每份最多 1 GiB；唯一视频轨，最多一个音轨。
- 完整解码视频和音轨，检查每帧 PTS 的 CFR 网格、音频连续性、实际样本数与有理数起点；登记副本完整 SHA 与上传原片相同。
- 变帧率、多音轨、缺失 PTS、非方形像素、旋转或中途变画幅需要明确另存处理，不偷偷选择音轨、补帧或重编码。
- 登记保留真实起点；现有 24fps 整片导出不能静默归零非零起点。非24fps或非零起点的外片需先明确处理成新素材，再登记新版本。原片不变。
- 外片续拍另由独立 [Source／Encode／Conditions 入口](EXTERNAL_CONTINUATION_EXP.md) 处理；登记本身不执行续拍。显式 CFR 转换并未实现，不偷偷转换原片。

## 故障与工程包

登记前冻结请求 UUID 和已保存项目身份。响应不确定时，关闭/刷新后重试原请求；不自动换 UUID。浏览器不能保存原请求时不发送登记。服务端确认从未登记才释放该请求；已存在或部分提交的目标不覆盖。

每个版本有独立固定副本和回执。副本缺失、改动或回执损坏会报告错误，不换用原资产或其它旧片。迟到响应不会改动切换后的项目、镜头或编辑窗口。

工程包只携带外片标记与人工来源类别，不携带原绝对路径或虚构采样参数。导入时以实际包内媒体重新测量时钟、核对 SHA，并创建新项目/版本身份，保留外片不可重采样属性及采用范围。

当前55个完整 CPU 测试范围共658项通过，无skip/deselect/xfail；其中两个live检查连接真实本任务ComfyUI服务，不是仅静态HTTP夹具。当前Chromium实际文件选择上传→登记不改/不采用→手动采用→整数裁切→Save/重开/解码播放也通过，源与原片完整SHA保持，自有服务已关闭。此前117项夹具范围包含丢响应幂等重试、迟到响应、存储失败、非零起点和工程包重开，属于658覆盖内，不相加。CUDA未初始化；没有在此资格里Queue/加载模型，不等同新外片续拍的原生采样或人审资格。三个原库/负例警告及历史失败保留。未发布。
