# H07：给现有视频生成动作拟音

导入 [A6_Foley_Half.json](../examples/workflows/85-h07-reviewed/A6_Foley_Half.json)。
这是“保留原画面、重新生成声音”的配方，不是文字转语音、配音或声音克隆。
本次5秒注液／关龙头／移杯样片已获人工通过，其他动作仍需试听。

## 使用步骤

1. 在节点1 `LoadVideo` 选择自己的合法视频。建议先用5秒、24fps、864×480且
   发声动作清楚的素材，例如倒水、关门、放杯。先去掉原录音，以免源音频影响
   音频latent初始化；示例验收使用精确静音源，不混用现场声证明拟音能力。
2. 节点11选择匹配的 `minimax_h3_hybrid_fl2va_ref2va_b25-49-int8.safetensors`；
   节点10选H3兼容Qwen，节点7／8分别选择H3视频／音频VAE。
   本配方复用已有模型与节点，不需要独立拟音模型或外部LanPaint sampler。
3. 节点14写清画面动作、声音和发生时间。例如：

   > 一段连续镜头，杯中持续注水；约3.5秒关闭水龙头，水声停止，随后轻放杯子。
   > 只生成与画面同步的自然水流声、关闭龙头的轻响和杯子接触声。
   > 不要对白、人声、笑声、音乐或电流杂音。

   导出模板保留已审英文提示词；换视频时应同步重写，不能继续描述无关的啤酒龙头。
4. 保留节点6 `SolidMask=0`（视频已知），节点9的全时段音频重生成区域
   （AUDIO mask=1），节点14 `audio_mode=native`、`audio_denoise_strength=1`。
   节点9 `require_lanpaint_sampler=false` 是此已审配方，不要求安装外部LanPaint。
5. 运行画布。节点21 `OutputTrim` 的 `frames` 必须接节点3原画面，`audio`接
   节点20 `AVDecode` 的生成音轨，再由节点22保存。这条原画面旁路很重要：
   不要把内部半尺寸解码画面当成最终视频。
6. 检查生成音轨与可见动作是否同步、有无杂音或意外人声。若还需要对白或音乐，
   在独立后期混音，不把那些录音混入本次模型拟音的验收结论。

## 尺寸、时长与限制

已审图：最终864×480／120帧／24fps／5秒；内部画面按area缩至432×240，
四边各补8像素成为448×256。采样为40原生步、VIDEO mask0／AUDIO mask1；
124帧时钟含末尾4帧，最终裁回5秒。它不是双采放大，不必额外接learned1.2×。

换尺寸需同时修改节点3最终尺寸、节点4半尺寸、节点5网格padding、节点6 MASK
及节点14条件尺寸，保证内部几何一致。换时长需同步Conform length、音频重生成
区间和OutputTrim，不只改播放器时长；先以已审5秒配方开始最方便。

联合AV transformer并非数学隔离的音频模型，声音自然度、响度和同步并不保证。
最终视频会重新编码，不是压缩字节原封不动；不承诺6×加速。旧空庭院失败案例
不能证明动作拟音质量，只有本次可见注液样片被接受。
