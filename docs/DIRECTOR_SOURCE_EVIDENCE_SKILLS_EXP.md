# 导演台：镜头证据、创作修订与 Prompt 规则（EXP）

在导演台“更多 → 镜头证据与规则”使用。旧工程没有这些字段时保持旧编译、原文、事件、时钟和生成路线，不强制增加审核，不自动生成或保存。

## 源视频证据

先把视频登记到素材库，再在面板选择源视频、点击“测量源时码并创建模板”。独立CPU媒体工作进程读取真实视频轨道、timebase、起止PTS；缺失边界会明确报错，不猜24fps或悄悄舍入。该测量只是容器头信息，不是完整解码、VFR转CFR或质量验收。

可以添加人工观察，或导入 `t8.director.source_evidence.v1` JSON。visual、ocr、asr、audio、end_state分别记录，绑定来源UUID与SHA。ASR须声明独立音频来源、实际采样率与范围；多音轨须明确stream。不会用画面猜台词、按置信度自动确认，也不会下载语音模型或把原片送到云端。

导入不会确认。勾选条目并明确点击确认，记录绑定本版packet SHA和review revision。修改包或更换源文件字节使旧确认失效；旧回执保留，不重签。查看有理数映射可分别看到绝对源时间、本镜局部时间与输出帧位置。采样的事件帧网格和音频样本不因此改变。

## 创作修订

观察事实不会因创作目标被改写。例如“原帧是红衣”和“希望改成蓝衣”分别记录，候选稿明确标注来源类型和创作意图，不保证模型一定服从文字。

更新观察、确认、创作意图或生成新候选时，旧内容与回执完整进入只读修订历史；历史不参与当前采样。同一证据ID修改内容必须增加revision，创作revision递增，不能偷偷覆盖同一版。已保存历史不能改写或删除；需要剥离私密历史时另存新工程，或默认不携带扩展的工程包。记录超过整体512KiB/单列表256项会报错并保留原稿，不静默截断。

跨镜依赖只接受明确的镜头UUID与已确认evidence SHA。所依赖事实变化、删除或确认失效会使消费候选stale；无关镜头原文编辑不会传播到所有镜头。原歌词、对白事件和Relay时钟不重新解析或自动改写。

## 逐镜规则快照

规则是声明式文字，不是可执行Codex技能。每份快照包含ID、version、文字、参数schema与content SHA。全片绑定先于本镜绑定；可分别启用、排序、移除、本镜禁用共享条目，或关闭全片继承。删除库条目不删除既有绑定，完整绑定自足，导出到没有规则库的新工程仍可重新编译。

参数仅支持string/number/integer/boolean和一次 `${name}` 字面替换，支持默认值、范围、长度、choices；没有Python、JS、shell、Jinja执行或URL请求。素材引用仍走现有UUID→Picture/Video/Audio编译，不改变原编号语义。同ID/version不同内容会拒绝，需要显式新版本，不能静默取latest。

## 候选、采用与回退

点击“编译待审候选”只生成独立稿件与消费回执，原作者稿不变。是否包含已确认事实和创作意图由控件选择。已确认ASR仍作为证据标注，不自动变成角色台词。

明确采用后，当前有效候选才作为本镜local prompt进入既有编译，global和事件沿旧逻辑继续处理。原稿、资产顺序、事实/修订版本、实际规则顺序/参数或明确依赖改变，执行预检拒绝失效候选；重新编译审核，或“退回原作者稿”。不覆盖采用成片，不自动改QualityGate/confirm。

“配置已修改”也包含已采用候选及其实际消费依赖；未采用候选、只读历史、未启用规则和未消费的事实/创作草稿不计作新的采样配置。批选单镜保留其明确跨镜事实，冻结依赖来源字节，但不因为另一镜未完成的提示词而阻止当前镜。

## 保存与工程包

正常项目保存、JSON和浏览器草稿保留新字段，revision冲突不会覆盖另一稿。草稿操作接口本身不自动Save或Queue。

工程包默认不带证据/规则/候选扩展，也不带只用于证据且没有其它创作用途的原视频/音频；原有参考或创作收藏使用的素材仍按原工程包政策保留。需要完整迁移时，勾选“包含证据、规则快照与候选稿”并检查实际文字与媒体清单：可能包含ASR/OCR私密原文。模型、密钥和原始provider响应不打包。

导入新工程会重映射素材/镜头身份。旧确认SHA/revision保留为历史stale，候选退回非活动状态，原稿与候选文字均保留；不把新身份重签成已审核，不捏造旧采样祖先。重新核对后可确认、编译和采用。

旧历史中的原身份/内容SHA保持不变，仅作非执行溯源，不要求历史素材仍在当前素材库；当前证据重映射形成新的revision。普通LAN HTTP没有SubtleCrypto时仍计算同一UTF-8 SHA256，并沿既有getRandomValues生成UUID，不因此关闭内容核对。此为能力回退，不意味着HTTP连接经过加密。

## 边界

一份当前保存的 QA 工程已用原生画布实际 SaveAs、刷新重开与 Queue：源证据、独立创作意图和全片/本镜规则快照编译的候选，经明确 literal SHA 采用后完成原四步采样，交付完整120帧608×320、24fps、精确5秒音画并严格解码。QA 确认不是用户对事实、权利或画质的确认；最终人审仍独立。

私有只读观察器未替换 Core callable、删改历史或关闭原默认缓存。同输入再次排队，以及只更换节点ID，均没有再次执行 Qwen 编码；更换提示词才重新编码。因此当前原生图不叠加第二套全输出 conditioning 缓存。这不是串行 renderer 内部所有调用、任意 CLIP/hook、跨进程缓存或一般提速认证。

目前这是本地EXP。容器头、SHA、CPU/浏览器测试分别证明时码/内容身份和操作行为，不证明观察真实性、真人身份、授权、生成画质或通用性能。自动语义分析/云端provider没有隐式接入；若未来接入，需要绑定实际请求范围的明确授权。

没有更改旧采样数学、模型/LoRA准入、EAV/Relay、恢复合同或音频。新功能不把未确认候选当成已完成Stage，也不认证跨进程不透明对象缓存。
