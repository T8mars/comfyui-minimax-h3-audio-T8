# RealBasicVSR / MMagic attribution

The optional `MiniMaxH3RealBasicVSRRestoreT8Advanced` inference architecture is
adapted from OpenMMLab MMagic's implementations of RealBasicVSR, BasicVSR and
SPyNet.

- Project: https://github.com/open-mmlab/mmagic
- Upstream copyright: OpenMMLab
- Upstream license: Apache License 2.0
- Paper: *Investigating Tradeoffs in Real-World Video Super-Resolution*

Only the dependency-light inference architecture is included. This repository
does not bundle OpenMMLab model weights and does not download them at runtime.
