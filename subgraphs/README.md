# MiniMax H3 Quick Start 子图

这里的 JSON 是 ComfyUI 原生子图蓝图。重启或刷新 ComfyUI 后，可在子图/蓝图入口中直接搜索 `MiniMax H3 Quick`。

七个入口分别覆盖文生音视频、首尾帧、参考生音视频、原音轨驱动、长视频、单人五官修复和Creator同步音画审片。它们只是把已经验证的工作流封装为更少的外露参数，不会修改旧节点的输入顺序、默认值或旧工作流文件。

文件名统一使用带发布日期的ASCII形式，避免Comfy Registry在部分Git/Windows环境把中文路径转义后漏打包；子图在ComfyUI里显示的中英文标题保持不变。

- 首尾帧：连接首帧即可做 I2VA，同时连接尾帧则进入 FL2VA。
- 原音轨驱动：输入音频同时作为生成条件与最终保留音轨；这不等同于承诺任意素材的精确口型同步。
- 长视频：默认不自动接受候选片段，仍需人工审片后开启 `accept_after_review`。
- 单人五官修复：使用清晰的同一人物参考图；它修复五官结构，不承担模糊视频锐化。
- Creator同步音画审片：A/B必须是同内容、同起点的两条带音轨视频；画面不拉伸，保存的并排视频故意无声，两路音频必须分别完整试听。默认结论为`ABSTAIN`，节点不会自动替用户选择胜者。

这些文件由 `tools/build_quickstart_subgraphs.py` 确定性生成，修改来源或公开参数后需要重新运行生成器并执行对应测试。
