# SPEED S17 分离式研究图（EXP）

这里有 82 张 T2VA 示范图：2 阶段 30 张、3 阶段 52 张。每组覆盖无效果，或把外置 EAV、Prompt Relay、两者组合分别接到单一阶段或所有阶段；每种配置有完整不存阶段、完整保存阶段及从已有阶段回执冷启动后段的图。三阶段分别提供从 Stage0、Stage1 回执恢复的图。独立的 MODEL、可插 LoRA、Source/Conditioning、Sampler、阶段噪声和 DCT 转段均可见，不再只能通过旧整链节点操作。

建议从 `none_none_full_save` 看基础连线，再看 `combined_all_full_save` 中每个阶段独立的 Relay Plan／EAV Config。`cold_1`、`cold_2` 必须填写对应完整图实际保存的相对 manifest 路径与精确 SHA；空占位不可直接排队。冷图只选择并认证冻结结果，不会根据当前前段控件变化自动重算。文件名中的效果作用范围记录完整运行时的预期来源；若该阶段已冻结，冷图不会再次执行其效果节点。

本组使用手工 sigma 仅作分离机制示范。旧用户盲评已否决固定 SPEED 计划，**不要将这些数值作为画质或速度推荐**。原 `10-speed` 一体图、节点及默认参数没有迁移或覆盖。这里也没有宣称 I2VA、FL2VA、L2VA、Ref2VA、Hybrid、参考视频／音频等其它 SPEED 输入形态已有相应正式分离图；它们仍在 S17 后续清单中。EAV 默认为 `report_only`，不施加增强；`apply_exp` 的质量需独立验收。

现有验证范围为 Core 静态图 82/82、隔离真实前端逐图另存重开 82/82、五张代表图可见 Relay/EAV 编辑，以及此前阶段小尺寸机械证据。原尺寸预训练 GPU 音画、更多后端/素材、质量/显存和人工验收不能由可导入性推断。旧图继续可用。
