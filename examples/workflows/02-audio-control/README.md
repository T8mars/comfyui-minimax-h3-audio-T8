# 音频控制

这一组控制来源音频如何参与联合音画生成，并提供按时间计划注入驱动音频的高级实验。

## 工作流

- `Audio_Lock_Source`：尽量锁定来源音频，适合希望画面变化但原声保持的场景。
- `Audio_Remix_Source`：允许模型对来源声音重混和再演绎。
- `Audio_Reference_Only`：音频只作为参考，不把来源音轨锁进目标latent。
- `Scheduled_Audio_Injection`：按时间段规划驱动音频，属于Advanced EXP。

## 当前成果

三种稳定音频模式已覆盖输入校验、32kHz双声道、音画时长及旧工作流兼容回归。计划式注入已有结构与时间线检查，但复杂场景仍需试听。

## 使用方法与注意事项

先确认接入的是ComfyUI原生 `AUDIO`，不是文件名或波形数组。需要完整保留原音乐/环境声时优先 `lock_source`；希望重新演绎时使用 `remix_source`。所有联合AV模式都应同时检查最终画面和声音，不能只看视频。
