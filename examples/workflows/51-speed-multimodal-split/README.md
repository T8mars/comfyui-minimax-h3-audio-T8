# SPEED S17 多模态两阶段分离研究图（EXP）

本目录为旧 SPEED 多模态输入形态补充可编辑的两阶段入口，共六种来源×十种阶段效果作用配置×三种完整／保存／冷后段形式，计180张图。六种来源是 I2VA 锁定原音频、FL2VA 重混源音频、L2VA 原生音频、Ref2VA 图片参考、Ref2VA 视频＋关联音频参考、Hybrid 首帧＋独立图片和音频参考。效果配置包含无效果，以及 EAV、Prompt Relay、两者组合分别作用于 Stage0、Stage1 或两阶段。旧 `10-speed` 工作流和整链节点保留。

视频输入沿原 SPEED 公开示例的来源合同先显式截取：I2VA／FL2VA／L2VA 要提供精确24fps且覆盖124帧的源视频；视频参考取前2秒，并须符合原2–15秒参考政策。图片与视频文件名是待替换占位，不可直接排队。每个活动阶段仍独立从这些原始素材在本阶段画布重新编码，`reuse_t2va_text=false`；I2VA 最终使用所选源切片的原音频，其它模式用生成音频，末端裁到124帧。请按实际素材核对图片/视频和音轨顺序及提示词中的 `<Picture 1>`／`<Video 1>`／`<Audio 1>` 标签。

从 `none_none_full_save` 理解原素材与两段 DCT 转段，再查看 `combined_all_full_save` 的两套独立 Relay Plan／EAV Config。`cold_1` 需要填完整图实际 Stage0 保存的相对 manifest 路径和 SHA；它选定旧结果而不重新采样 Stage0，也不会因当前前段设置变化自动命中。EAV 默认 `report_only`。手工 sigma 是被旧用户盲评否决的研究计划，仅用于分段机械示范，不代表质量或速度推荐。

已对180/180张做当前 Core 静态校验与隔离真实前端另存重开；六种输入形态各取完整保存和冷后段共12张，经可见 Relay/EAV 控件编辑后重开保持。六种来源也用 tiny Core 核对了两个阶段 Relay 重建的 AV 目标；视频＋音频参考及 Hybrid 另核对了小尺寸外置 Relay/EAV 首段保存、读取并继续后段的执行回执。这些都不自动证明原尺寸预训练 GPU 音画、其它 LoRA／后端、EAV `apply_exp` 画质、音频听感、显存、旧图同参数逐帧等价或人工验收。三阶段多模态和 SPEED Turbo8 仍单独待办。
