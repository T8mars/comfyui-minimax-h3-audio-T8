# 基础生成与双时钟采样

这一组用于建立最小可运行的 MiniMax H3 音画生成链，重点展示视频/音频双时钟以及 Turbo LoRA 的稳定4V4A和实验性4V8A、4V10A采样。

## 推荐入口

- `2026-08-06_H3_Turbo_Stable_4V4A.json`：默认优先，视频4步、音频4步。
- `2026-08-06_H3_Turbo_EXP_4V8A.json`：视频4步、音频8步，音频计算更多。
- `2026-08-06_H3_Turbo_EXP_4V10A.json`：视频4步、音频10步，仅作多速率实验。

## 当前成果

稳定4V4A是项目长期兼容基线；多速率路线已完成机械、时钟和输出契约回归，但不等于所有素材上声音必然优于4V4A。

## 使用方法与注意事项

替换模型、CLIP、双VAE和媒体输入后运行。Turbo LoRA必须与对应H3基座匹配；不要仅凭文件名强行加载未知LoRA。首次排错先用稳定4V4A，不要同时叠加SPEED、Restart、STG或Block Cache。
