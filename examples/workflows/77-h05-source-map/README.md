# 同源 RGB / MASK 帧映射（H05 N02，EXP）

导入 `H05_Source_Map_EXP.json`。这是实际从原生画布保存、运行过的机械验证图，
不是局部物体编辑成片或新的推荐采样配方；旧工作流无需修改。

在 Load Video 选择自己的输入视频。示例名 `N02_Source_5s.mp4` 是本机验配素材，
视频不随仓库发行。固定验配使用 120 帧、24 fps、5 秒：准备到 124 帧时末帧保持
4 帧，音频补零可从报告检查；最终保存截取前 120 帧，并接原解码音轨。
换用其他时长或 fps 时，应明确同步准备长度、截取长度和 Create Video fps，
不能把本例固定的 5 秒设置当作任意素材的自动时钟。

RGB 和 LOW / HIGH MASK 三支共用同一 frame_map，LOW 为 448×256，HIGH 为
512×288，各支几何和内容摘要分别报告。绿色通道 MASK 只验证逐帧数据接线，
**不是杯子、人脸或遮挡标注**。真实局部编辑需替换成完整源逐帧标注，
不可见帧置零，再分别保存原始候选与可选 composite，不能用回贴掩盖失败。

本例不加载扩散模型、没有新采样 NFE。已完成实际 CPU 画布运行和完整音画
解码，但没有由此认证局部编辑 GPU 质量、音频重新编码无损或任意素材效果。
节点及默认用户目录需使用包含这四个 EXP 节点的后端；本地开发不等于 GitHub
或 Registry 已发布。

接口和证据边界见 [Source Conform](../../../docs/SOURCE_CONFORM_EXP.md)。
